# Extra notes

The main write-up lives in [../README.md](../README.md). This folder is just the longer "how a card gets built" page.

- [HOW-ITEMS-ARE-CREATED.md](HOW-ITEMS-ARE-CREATED.md) — what happens when you tap Create

Live page: https://raw.githack.com/Climer00/table-loot-forge/main/index.html

Quick version:

- Two taps: rarity + type, then Create
- Crate is for a chest or boss pile after a fight
- Desk mode is the wide PC layout; Table mode is the phone column
- Sets only land on lasting gear, not potions / tinctures / scrolls
- Share sends the card picture. Copy sends the words.

Fan tool. Not Wizards.
