## Current behavior (quick)

- **Table path:** rarity → type → Create
- **Card:** name, category, look, named kits, set bonus, lore
- **Share:** image-only PNG of the card
- **Copy:** clean player text
- **History:** last ~30 full items on this device
- **Sets:** two items that share a first name-word grant one extra rider; same property does not double

Fan tool. Not affiliated with Wizards of the Coast.
